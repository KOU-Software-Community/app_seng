MOBILE'A AKTARIM
1 · Kod paketi al
Bu tasarımı Claude Code handoff paketi olarak dışa aktarabilirim: ekran ekran spec, renk/tipografi token'ları ve component listesi. "Handoff paketi çıkar" de, hazırlayayım.
2 · Teknoloji seç
Tek kod tabanıyla iOS + Android için React Native (Expo) öneririm — burada kullanılan layout mantığı birebir karşılık buluyor. Expo Router = burada gördüğün tab + stack navigasyonu.
3 · Token'ları taşı
5 renk + Plus Jakarta Sans + Press Start 2P (yalnız rozet/pixel) bir theme dosyasına; radius 8–16, spacing 4'ün katları.
4 · Backend
Etkinlik/kayıt/bildirim için Firebase (Firestore + Cloud Messaging) en hızlısı; kayıt formu tek koleksiyon.
